# WhatsRook Web Showcase & Dashboard

A lightweight, high-performance web dashboard for WhatsRook built entirely in pure Go using [`github.com/Thruqe/htmlbuilder`](https://github.com/Thruqe/htmlbuilder).

## Features

- **100% Pure Go**: Zero raw HTML template files, zero JavaScript framework dependencies, zero Node.js / Bun toolchain.
- **Type-Safe Component Builder**: Webpage layouts, typography, CSS styling, and glassmorphism design compiled directly into the Go server binary.
- **Dark Mode Aesthetic**: Custom color palette, glassmorphism cards, micro-animations, and responsive layout math.

## Running the Web Application

To run the web showcase locally:

```bash
cd example/web
go run main.go
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.
